# Workday → Okta Connector

Generated by **Aivar Discovery Agent — Level 3**.

## Authentication

**Type:** `bearer`

To obtain a bearer token, you need to create an Okta API token in the Okta Admin Dashboard. Go to Security > API, then click on the Tokens tab and click Create Token.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Provide your API token via environment variable or pass directly:
   ```bash
   export API_TOKEN="your-token-here"
   ```

## Usage

```python
from connector import WorkdayToOktaConnector

client = WorkdayToOktaConnector(api_token="your-token-here")

# List all staff records
records = client.list_records()

# Get a single record by ID
record = client.get_record("record-id")

# Create a new record
new_record = client.create_record({"field": "value"})

# Update an existing record
updated = client.update_record("record-id", {"field": "new-value"})
```
